# CryptoLab Pro - منصة محاكاة وتحليل خوارزميات التشفير 🛡️

منصة ويب تفاعلية متقدمة ومستقلة بالكامل (Offline-First) لمحاكاة وتحليل خوارزميات التشفير الكلاسيكية والحديثة، تنفيذ هجمات استعادة المفاتيح، وتشفير المستندات محلياً.

---

## 👨‍💻 بيانات المشروع والاعتماد الأكاديمي

* **المشروع:** مشروع مادة التشفير وأمن المعلومات (Cryptography & Information Security).
* **الجهة الأكاديمية:** جامعة المنار - كلية العلوم والهندسة.
* **إعداد وتطوير:** المهندس عرفات عبدالله الكاملي (Arfat Abdullah Alkamly).
* **التخصص:** قسم الأمن السيبراني والشبكات (Cybersecurity & Networks).

## 🌟 الميزات التقنية الرئيسية (Core Features)

### 1. التشفير الكلاسيكي وهجمات القوة الغاشمة (Classical Cryptanalysis)
* **خوارزمية قيصر (Caesar Cipher):** تنفيذ التشفير وفك التشفير الحسابي وفق المعادلة القياسية:
  $$C \equiv (P + K) \pmod{26}$$
* **أداة كسر التشفير (Brute Force Key Space Analysis):** تجربة تلقائية لكافة المفاتيح الممكنة ($K \in [1, 25]$) واسترجاع النص الأصلي فورياً.
* **خوارزمية بلايفير (Playfair Cipher):** بناء وتوليد مصفوفة $5 \times 5$ ديناميكية مع تطبيق قواعد الاستبدال الثنائي (Digram Substitution) تلقائياً.

### 2. معايير التشفير المتماثل الحديثة (Modern Symmetric Ciphers)
* **معيار AES-256-GCM:** تشفير متقدم يعتمد على واجهة التشفير الأصلية للمتصفحات (`Web Crypto API`) مع دعم نظام اشتقاق المفاتيح الآمن `PBKDF2` والتمليح العشوائي (Salt & IV).
* **معيار DES المدمج:** تشفير الكتل المتماثل ومحاكاة عمليات الإزاحة والـ XOR.

### 3. نظام تشفير المستندات (Client-Side File Encryption)
* تشفير الملفات النصية محلياً وحفظها بامتداد `.enc`.
* فك تشفير الملفات واستعادتها بصيغتها الأصلية مع التحقق التام من مطابقة المفتاح.

### 4. دوال التجزئة واختبار الانهيار الثلجي (Cryptographic Hashing & Avalanche Effect)
* **خوارزمية SHA-256:** توليد البصمات الرقمية (Hashes) بطول 256-bit في الوقت الفعلي.
* **اختبار الأثر الجذري (Avalanche Effect):** مقارنة مرئية توضح كيف أن تغييراً طفيفاً في حرف أو بت واحد يؤدي لتغير شامل في قيمة الهاش الناتجة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Frontend:** HTML5, Modern CSS3 (Dark Futuristic UI).
* **Core Logic:** Vanilla JavaScript (ES6+).
