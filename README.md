# CryptoLab Pro

منصة ويب تعليمية تفاعلية لاستكشاف خوارزميات التشفير الكلاسيكية وبعض واجهات Web Crypto API داخل المتصفح.

- **النوع:** مشروع أكاديمي فردي لمادة التشفير وأمن المعلومات.
- **التطوير:** عرفات عبدالله الكاملي.
- **التقنيات:** HTML5، CSS3، JavaScript، Web Crypto API.
- **التشغيل:** افتح `index.html` في متصفح حديث. يلزم سياق آمن (HTTPS أو localhost) لواجهات Web Crypto في المتصفحات التي تفرض ذلك.

## الوظائف الموجودة في المصدر

| الوحدة | ما ينفذه التطبيق |
|---|---|
| Caesar | تشفير وفك تشفير قيصر وتجربة الإزاحات من 1 إلى 25 |
| Playfair | إنشاء مصفوفة 5×5 وتطبيق تحويل أزواج الحروف |
| AES-GCM | تشفير وفك تشفير نصوص باستخدام AES-256-GCM ومفتاح مشتق عبر PBKDF2-SHA-256 |
| File encryption | تشفير محتوى الملفات النصية وفكّه محليًا بصيغة Base64 مع Salt وIV |
| SHA-256 | حساب بصمات SHA-256 لنصين ومقارنة النتائج |
| XOR demo | تجربة XOR بسيطة للتوضيح التعليمي فقط |

## ملاحظات أمنية ودقة التسمية

- وحدة XOR **ليست خوارزمية DES** ولا توفر أمانًا تشفيريًا؛ إنها محاكاة تعليمية مبسطة لعملية XOR بمفتاح مشتق بطريقة غير معيارية. لا تستخدم لحماية بيانات حقيقية.
- تشفير الملفات الحالي يقرأ الملف كنص عبر `FileReader.readAsText`؛ لذلك لا ينبغي وصفه بأنه تشفير عام لكل أنواع الملفات الثنائية.
- AES-GCM هو الخيار التشفيري الحديث المعروض. استخدم كلمات مرور قوية، ولا تعِد استخدام Salt أو IV يدويًا؛ التطبيق يولدهما عشوائيًا عند التشفير.
- المشروع تعليمي، ولم تُنشر معه نتائج تدقيق أمني مستقل أو اختبارات توافق شاملة. لا تعتمد عليه كمنتج لحماية معلومات حساسة.
- ميزات تحليل قيصر وبلايفير مخصصة للتعلم؛ الخوارزميات الكلاسيكية غير مناسبة لحماية الاتصالات الحديثة.

## البنية

- `index.html`: الواجهة العربية وأقسام التجارب.
- `style.css`: التنسيق والتصميم.
- `app.js`: منطق التشفير والتجزئة ومعالجة الملفات.
